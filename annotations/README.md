# Annotations

Annotation files are intentionally kept separate from the compiled OpenAIRE data.

The shared source data live under:

`data/openaire_zenodo_12819872/`

This directory should contain only manually created labels, annotation guidelines,
sample assignments, or adjudication outputs. Do not add annotation columns to the
shared data CSVs.

A validation sample will be generated later from
`data/openaire_zenodo_12819872/github_repositories.csv`.
