# Shared OpenAIRE GitHub Software Data

This directory contains reusable datasets derived from Zenodo/OpenAIRE software record `12819872`.

Do not add manual annotation columns here. Annotation data belong under `annotations/`.

Canonical generation command:

```bash
python scripts/compile_openaire_github_dataset.py /path/to/software.tar
```

See the repository-level `DATA_FLOW.md` and the generated `data_flow.json` for full provenance and transformation details.
